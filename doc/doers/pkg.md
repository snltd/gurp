# pkg

Install and uninstall pkg(5) packages.

## Resource Name

Package name, of the form ooce/editor/helix (`:string`)

## pkg/ensure

```janet
(pkg/ensure "ooce/developer/rust")
```

### Mandatory Properties

None

### Optional Properties

None

## pkg/remove

```janet
(pkg/remove "ooce/developer/go")
```

### Mandatory Properties

None

### Optional Properties

None
