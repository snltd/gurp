# pkgin

Install and uninstall pkgin packages. Only valid in a pkgsrc                 zone.

## pkgin/ensure

```janet
(pkgin/ensure "rust")
```

### Mandatory Properties

None

### Optional Properties

None

## pkgin/remove

```janet
(pkgin/remove "go")
```

### Mandatory Properties

None

### Optional Properties

None

There is no pkgin/remove.
