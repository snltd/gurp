# apk

Install and uninstall APK packages. Only valid in an Alpine LX zone.

## Resource Name

Package name (`:string`)

## apk/ensure

```janet
(apk/ensure "rust")
```

### Mandatory Properties

None

### Optional Properties

None

## apk/remove

```janet
(apk/remove "go")
```

### Mandatory Properties

None

### Optional Properties

None
