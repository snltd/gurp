## Janet Source

Where we store the Janet macros and functions which build the structure we feed
into the Rust backend.

Tests require
[a Janet installation](https://github.com/janet-lang/janet/releases) with
[JPM](https://janet-lang.org/docs/jpm.html) and
[Judge](https://github.com/ianthehenry/judge). They will run on any operating
system.

To test, just run `judge`, or use the `Dockerfile`.
